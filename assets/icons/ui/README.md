# Ícones atuais da interface

Os SVGs em `actions/`, `align/`, `navigation/`, `objects/` e `state/` são recursos utilizados pela interface. A origem por arquivo, adaptações e avisos estão no [inventário de procedência](../../../docs/ASSET_PROVENANCE.md); os textos das licenças ficam em [docs/licenses](../../../docs/licenses/).

O programa aplica cores do tema aos desenhos monocromáticos. Preserve os nomes usados pelo código, o `viewBox` e a geometria ao substituir um recurso. Antes de remover um ícone, procure suas referências, inclusive nomes montados dinamicamente.

O antigo catálogo de pedidos não representa o conjunto atual. O `README.pdf` remanescente é material histórico de desenvolvimento e não deve orientar novas alterações. Nenhum desses arquivos README integra o pacote do aplicativo.
