# Workspace novo

Interface de transição do COMSOC com o padrão visual do `editor_novo`.
Ela usa apenas `features.workspace_novo`, `features.spreadsheet_novo` e
`features.editor_novo`; o workspace e os editores anteriores continuam ativos.

Execute a partir da raiz do projeto:

```bash
.venv/bin/python features/workspace_novo/main.py
```
